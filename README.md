# Calorie Tracker

A private, offline-first calorie and nutrient tracker. Installable as a PWA on
your phone, usable on a laptop, with **no account, no server and no cloud
database** — every food you log stays in your browser's IndexedDB.

See [DESIGN.md](./DESIGN.md) for the full design rationale and data model.

## Features

- **Today** — calorie ring, macro donut, meals grouped by breakfast / lunch /
  dinner / snacks, and a short "what you missed" hint tuned to your diet type.
- **Add food** — four tabs:
  - *Search* the bundled food list (Indian, Italian, Western, Chinese) with
    aliases (`curd` finds yogurt) and serving units (idli, katori, slice, cup).
  - *Scan* a barcode on-device (`BarcodeDetector` with a ZXing fallback) and
    look up products on Open Food Facts — the result is cached locally so it is
    fetched once, and the packet total is shown.
  - *Manual* entry per 100 g with serving and packet weights.
  - *Recipe* builder that saves the per-serving result as a custom food.
- **History** — 7 / 30-day toggle with Calories, Foods and Nutrients tabs:
  bars with a goal line, food-type donut, cuisine mix, meal timing, top foods,
  nutrient-target bars and a per-nutrient trend line.
- **Profile** — body stats, goal and diet type, Mifflin-St Jeor BMR → TDEE →
  daily target with a safety floor, storage usage, persistent-storage request,
  JSON/CSV export, JSON import, and a delete-all danger zone.
- **i18n** — English, Tamil and Chinese from locale files.
- **PWA** — service worker, app icons, installable, works offline after the
  first load (except unknown barcode lookups).

## Stack

Vite · React 19 · TypeScript · Dexie (IndexedDB) · Chart.js ·
vite-plugin-pwa · @zxing/browser fallback for scanning.

## Commands

```bash
npm install
npm run dev        # local development
npm run typecheck  # tsc --noEmit
npm run build      # typecheck + production build into dist/
npm run preview    # serve a production build
```

The first visit needs to be online to load `public/seed/foods.json` into
IndexedDB; after that the app runs offline.

## Deploying

Static bundle in `dist/` — deploy to Vercel (or any static host). HTTPS is
required for camera access and the service worker. On Vercel:

- Build command `npm run build`, output directory `dist`.

## Notes and remaining work

- The seed list ships ~135 common dishes; the design target is a larger
  database (one JSON file per cuisine — adding foods needs no code change).
- Calorie floor and nutrient targets are common estimates, not medical advice.
- Data stays per-device until a sync backend is added; export a JSON backup
  regularly and consider requesting persistent storage in Profile.

## Icons

`public/icons/*` are generated by `node scripts/generate-icons.mjs`.
